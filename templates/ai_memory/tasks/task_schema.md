## 任务 ID

格式：`DC-YYYYMMDD-NNN`

- 日期使用任务首次进入知识库的日期。
- `NNN` 从 `001` 起，确保仓库内唯一。
- 旧任务在下一次启动、变更、阻塞或验收时补发 ID；不批量改写历史。

## 状态机

```text
待规划 → 可开始 → 进行中 → 阻塞
                    ↓
                  待验收 → 已完成

任意未完成状态 → 已取消
阻塞解除 → 可开始或进行中
```

## Definition of Ready（进入"可开始"前必须明确）

- 目标
- 范围内与范围外
- 优先级
- 风险
- 负责人
- 验收标准
- 验证计划
- 回滚点

## Definition of Done

- 每条验收标准有证据（命令 → 结果）
- diff 与范围一致
- 验证通过
- 无意外文件与凭据残留
- 文档已更新（修订记录 + 归档分卷索引）
- 独立复核通过（按风险分级）

代码写完 ≠ 完成；测试全绿 ≠ 完成；必须逐条对照验收标准。
