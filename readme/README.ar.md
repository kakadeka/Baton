**Baton هو نظام تعاون بالتتابع للمشاريع.** يتيح لـ Claude Code وCodex وCursor وDeepSeek Harness التناوب على صيانة **المشروع نفسه** عبر أجهزة مختلفة — يبقى التقدم والذاكرة ومواصفات التصميم والمهام وGit متسقة. **أنت تتحدث بشكل طبيعي؛ وهو يتكفل بالباقي.**

**ثلاث وعود جوهرية:**

1. **🔄 يمكن لأي شخص أن يتولى المهمة** — بدّل أداة الذكاء الاصطناعي أو الجهاز، وقل أمرًا واحدًا، وتابع من حيث توقفت تمامًا. لا حاجة لإعادة شرح المشروع.
2. **🎯 تنفيذ ما طُلب** — حدود المهام والمسارات المحمية تُفحص ميكانيكيًا عند الإغلاق، وتُثبَّت حقائق التصميم في المواصفات؛ والباقي تحرسه القواعد والمراجعة — الانحراف يُكتشف لا أن يُفاجأ به بعد ساعات.
3. **✅ «تم» تعني تم فعلًا** — الإغلاق يلتزم (commit) ويرفع (push) و**يتحقق من SHA البعيد** — لا مزيد من «التزمت محليًا لكنه لم يصل إلى GitHub، ومع ذلك قيل لك إنه تم».

## 🚀 بداية سريعة (DeepSeek Harness — سطر واحد)

> تستخدم DeepSeek Harness؟ هذا كل ما تحتاجه.

```powershell
dsh plugin --profile web add @kakadeka/dsh-baton
```

1. ثبّت واجهة DSH مرة واحدة: `npm i -g @deepseek-ai/dsh`
2. الصق السطر أعلاه واضغط Enter.
3. أعد تشغيل `dsh` — انتهى. أدوات `baton_*` الست عشرة نشطة الآن في ملفك التعريفي.

> يمكن التثبيت أيضًا من GitHub: `dsh plugin --profile web add github:kakadeka/Baton`
> تستخدم **Codex / Claude Code / Cursor** بدلًا من ذلك؟ انتقل إلى [التثبيت لأدوات الذكاء الاصطناعي الأخرى](#-install-for-other-ai-tools-codex--claude--cursor).

| # | الألم | إجابة Baton |
|---|---|---|
| 1 | كل صباح أو جهاز جديد: أي فرع؟ ماذا أُنجز أمس؟ هل البعيد محدّث؟ | قل **clock in** — فحوصات git تلقائية + مزامنة آمنة + قراءة التسليم والمهام → جدول المهام → أجب برقم |
| 2 | «التزمت محليًا لكن لم أرفع»؛ أوامر PowerShell يدوية ليلًا | قل **clock out** — تحقق → مستندات/ذاكرة/مقاييس → commit → push → **SHA البعيد == HEAD المحلي قبل «تم»** |
| 3 | اختلط إنهاء مهمة مع «نهاية اليوم» | قل **complete task** — أغلق المهمة، سجّل النتائج، اقترح التالي. انتهاء المهمة ≠ نهاية اليوم |

| 5 | جلسة ضائعة، محادثة جديدة، إعادة شرح كل شيء | قل **continue work** — استعد المهمة/الفرع/العائق/التسليم/الخطوة التالية. جملة واحدة وتنتهي |
| 6 | مهام متعددة؛ الذكاء الاصطناعي لا يقرر الأولويات؛ كتابة المهام كاملة مرهقة | جدول مهام مرقّم — أجب `1`/`2`/`3` |
| 7 | مشروع طويل وتاريخ يتعذر الوصول إليه؛ إعادة القراءة تحرق الرموز | القرارات/المزالق/المواصفات تُفهرس تلقائيًا؛ **استعلم الفهرس واقرأ الجزء المطابق فقط** |
| 8 | تتابع Codex/Claude/Cursor دون معرفة ما فعله السابق | ملف تسليم موحد — الفرع/HEAD/التغييرات/القيود/الخطوة التالية. اقرأ آخر إدخال وتابع |
| 9 | نموذج مكلف لكل شيء؛ النموذج الضعيف يخطئ؛ التبديل اليدوي مؤلم | توجيه تلقائي للنماذج حسب صعوبة المهمة — micro: الجلسة الرئيسية، عادي: flash، معقد/مراجعة: pro، مع سلاسل بديلة |
| 10 | «أي نموذج عمل فعلًا؟» الفواتير لا تتطابق | يُسجَّل recommended وactual منفصلين، مع وسم المصدر بصدق (سجل إيفاد / واصف المضيف / غير معروف) |
| 11 | الذكاء الاصطناعي ينحرف عن النموذج الأولي بعد ساعات من العمل | متطلبات مجمّدة + مسارات مسموحة/محمية + فحوصات نطاق ميكانيكية + مراجعة مستقلة + لا git خطير |
| 12 | تغيير لون زر استغرق ساعة | مسار micro السريع — لا تفويض، لا مراجع، لا اختبارات غير ذات صلة. المهام البسيطة تستغرق دقائق |
| 13 | المهام المعقدة لا يجوز تنفيذها بإهمال | بوابات متصاعدة: عقد، نموذج قوي، مراجع مستقل، دقة مقابل المواصفات المجمّدة، خطة تراجع |
| 14 | جهازا المكتب والمنزل غير متزامنين؛ خوف من فقدان العمل المحلي | جلب آمن + مزامنة ff-only (لا تكتب فوق أبدًا)، commit/push تلقائيان، تحقق من SHA البعيد؛ force/reset/clean محظورة |
| 15 | اختيار النماذج بالتخمين، بلا بيانات حقيقية | كل مهمة تسجّل النموذج الفعلي والإنجاز → لوحة شهرية؛ النجاح/الفشل/المدة غير المجمعة بعد تُعرض «غير مسجلة» ولا تُختلق أبدًا |
| 16 | إعادة استخدام/مشاركة النظام مع مشروع جديد | الإطار ونسخة المشروع منفصلان تمامًا؛ `Baton init` تهيئة واحدة؛ المشاركة عبر خط تعقيم (بلا مفاتيح/مسارات/ملاحظات خاصة) |
| 17 | مهارات أخرى مثبتة تتجاوز قواعد المشروع | المهارات الخارجية قد تساعد، لكن حدود المشروع (المسارات، مواصفات التصميم، انضباط git) يفرضها Baton بالتنسيق مع AGENTS.md |

## ✨ الميزات (8 كتل قدرة)

- **أتمتة الأوامر** — clock in / clock out / continue work / save design spec / complete task / update project docs / remember / Baton init / تأكيد بالرقم / git بلغة طبيعية
- **عبر الذكاء الاصطناعي والأجهزة** — حقيقة المشروع كنص صافٍ + محولات رفيعة بأمر واحد (Codex/Claude/Cursor) + تسليم بالتتابع
- **ذاكرة طويلة المدى** — قرارات/مزالق/مواصفات مؤرشفة تلقائيًا + فهرس خفيف؛ قراءات تدريجية بلا إعادة قراءة كاملة
- **مكافحة الانحراف** — قيود مجمّدة + فحوصات المسارات المسموحة/المحمية + قائمة تغييرات محظورة + مراجعة مستقلة + لا git خطير
- **حلقة حقيقة Git** — مزامنة ff-only، commit/push تلقائيان، **SHA البعيد == HEAD المحلي**، سجل نشر (`last_published_sha`)
- **توجيه تلقائي للنماذج** — مستوى المهمة × جدول قواعد (flash/pro + مرتفع/أقصى + بديل)؛ recommended وactual يُسجلان بشفافية
- **لوحة شهرية** — ترتيب النماذج / النشاط بالساعة / التفاصيل اليومية / تفاصيل الوكيل، من بيانات تنفيذ حقيقية
- **قبول بنقرة واحدة** — `baton_accept`: فحوصات الهيكل/الحالة/الأمان/الحجم → PASS/FAIL + قائمة العوائق

## 🗣️ الأوامر (متى تستخدم كلًا منها)

قل أيًا من هذه العبارات الإنجليزية — المعنى متطابق في كل ذكاء اصطناعي. المشغلات الصينية متاحة في النسخة الصينية (الرابط بالأعلى).

| الأمر | متى | ماذا يحدث |
|---|---|---|
| **clock in** / *start work* | بداية اليوم / جهاز جديد / ذكاء اصطناعي جديد | فحوصات git → مزامنة آمنة → التسليم والمهام → جدول المهام |
| **clock out** / *end work* | نهاية يوم العمل | تحقق → مستندات/ذاكرة/مقاييس → commit → push → **تحقق SHA البعيد** |
| **continue work** / *resume* | جلسة ضائعة / أداة بدّلت | استعد المهمة والفرع والعائق ونهاية التسليم والخطوة التالية |
| **save design spec** | بعد تأكيدك تصميمًا | ثبّت في مواصفة دائمة + فهرس؛ مهام الواجهة تلتزم بها |
| **complete task** | مهمة انتهت وهناك المزيد | أغلق المهمة، سجّل النتيجة، اقترح التالي (بلا إغلاق كامل) |
| **update project docs** | نقطة تفتيش وسط العمل | اكتب التقدم + نقطة تفتيش التسليم (تظل مساحة العمل محجوزة) |
| **remember this pitfall** / *record this decision* | وقعت في مأزق / اتخذت قرارًا | اكتب في الذاكرة طويلة المدى + فهرسة تلقائية |
| **Baton init** | أول مرة في مشروع جديد | أنشئ هيكل الذاكرة + الإعدادات (لا يكتب فوق أبدًا) |
| أجب `1` / `2` / `3` | عُرض جدول المهام | يُثبَّت الرقم كمهمة حالية ثم يبدأ العمل |
| **release workspace** / *I confirm the previous agent stopped* | تعارض ملكية عند الدخول | حرر قفل الكاتب الوحيد + اكتب ملاحظة تحرير |
| **pull github** / *sync github* / *check git status* | نية git يدوية | مسار git خفيف، بلا طقوس عقد/مراجعة |
| **check update** | هل توجد نسخة جديدة من Baton؟ | قراءة مرساة الإصدار المحلية + الاستعلام عن أحدث إصدار من GitHub/npm والإبلاغ عن النتيجة |
| **update baton** / *upgrade baton* | توفّرت نسخة جديدة | ينفّذ الذكاء الاصطناعي التحديث كاملاً (git pull + إعادة تشغيل التثبيت / npm update) ويتحقق من تطابق النسخة المحلية مع البعيدة |

## 🛠️ التثبيت لأدوات الذكاء الاصطناعي الأخرى (Codex / Claude / Cursor)

> **التثبيت = انسخ أمرًا واحدًا، اضغط Enter، انتظر انتهاءه، ثم تحقق بأمر واحد.** لا إنشاء مجلدات يدويًا ولا نسخ ملفات يدويًا.
> مستخدمو DeepSeek Harness يمكنهم تخطي هذا القسم — استخدموا البداية السريعة أعلاه.

### الخطوة 0: قرر نوع التثبيت الذي تحتاجه (10 ثوانٍ)

| حالتك | ثبّت هذا | بعد التثبيت |
|---|---|---|
| مشاريع متعددة — تريد Baton متاحًا في **كل مشروع على هذا الجهاز** | **مستوى المستخدم** (مرة لكل جهاز) | عام على هذا الجهاز؛ أي مشروع يتعرف على الأوامر |
| **مشروع محدد** تريد أن تتولاه أجهزة/ذكاءات أخرى | **مستوى المشروع** (مرة لكل مشروع) | المشروع يحمل هيكل ذاكرته + محولات الأدوات الثلاثة؛ `git clone` وتابع |
| كلاهما | مستوى المستخدم أولًا ثم مستوى المشروع | الأكثر اكتمالًا |

> 💡 **موصى به**: نفّذ مستوى المستخدم (30 ثانية)، ثم مستوى المشروع على مشروعك الحقيقي (30 ثانية).

### الخطوة 1: نزّل Baton (مرة واحدة)

افتح PowerShell (اضغط `Win`، اكتب `powershell`، Enter) والصق هذا السطر:

```powershell
git clone https://github.com/kakadeka/Baton.git $HOME\Baton
```

> لا يوجد git؟ ثبّته من https://git-scm.com/download/win، وأعد فتح PowerShell، والصق مرة أخرى.

### الخطوة 2: اختر نوع تثبيت والصق أمره

**الخيار A — مستوى المستخدم (مرة لكل جهاز، كل المشاريع)**

```powershell
pwsh -File $HOME\Baton\scripts\baton-install.ps1 -Scope User
```

سترى `ok: [Codex] ...` و`ok: [Claude Code] ...` و`ok: [Cursor] ...` — تم تثبيت المهارة العامة لأدوات الذكاء الاصطناعي الثلاثة.

**الخيار B — مستوى المشروع (مرة لكل مشروع، يجعل المشروع قابلًا للنقل)**

```powershell
cd C:\your\project\path
pwsh -File $HOME\Baton\scripts\baton-install.ps1 -Scope Project
```

سترى سطر نجاح (اكتمل تثبيت مستوى المشروع) مع القائمة المنشأة (هيكل الذاكرة `docs/ai_memory`، الإعدادات `.baton`، ثلاثة نسخ من المهارة، وإدخالات في `AGENTS.md` / `CLAUDE.md` / `.cursorrules`). إذا قال إنه لا يوجد `.git`، نفّذ أوامر `git init` التي يطبعها.

> تثبيت مستوى المشروع تلقائي بالكامل و**يعمل بدون إضافة DeepSeek Harness** (وضع بلا إضافة).

### الخطوة 3: تحقق (المهم — أمر واحد)

في المشروع، قل لذكائك الاصطناعي:

```
clock in
```

**✅ نجاح**: يتصرف الذكاء الاصطناعي وفق Baton ويخرج تقرير حالة بالفرع وHEAD وحالة شجرة العمل والمهمة الحالية وملخص التسليم، يليه جدول مهام مثل —

```
Task table: 1) ...
```

**❌ لا شيء يحدث؟** تحقق بالترتيب:

1. أي ذكاء اصطناعي تستخدم؟ Claude Code → `~\.claude\skills\baton\SKILL.md`؛ Codex → `~\.agents\skills\baton\SKILL.md`؛ Cursor → `~\.cursor\skills\baton\SKILL.md` (تثبيت مستوى المستخدم ينشئ الثلاثة)
2. هل يملك المشروع `.git`؟ (وإلا `git init` + أول commit)
3. هل الأمر هو **clock in** بالضبط دون أي إضافة؟
4. هل يملك المشروع `docs/ai_memory/`؟ (تثبيت مستوى المشروع ينشئه)

### الخطوة 4: الانضمام إلى مشروع Baton قائم (جهاز جديد / ذكاء اصطناعي جديد)

على الجهاز الجديد: ثبّت git → `git clone` لمشروعك → قل لذكائك الاصطناعي:

```
clock in  أو  continue work
```

الذاكرة والتسليم والمهام تأتي مع الكود. تابع مباشرة — لا شيء آخر للتثبيت.

### ماذا يفعل سكربت النقرة الواحدة (بشفافية)

| الوضع | يفعل تلقائيًا |
|---|---|
| مستوى المستخدم | ينسخ `SKILL.md` إلى مجلدات المهارات العامة لأدوات الذكاء الاصطناعي الثلاثة (Codex / Claude Code / Cursor) |
| مستوى المشروع | ① هيكل `docs/ai_memory/` (مع سجل المراجعات + فهرس الأرشيف) ② `.baton/config.json` ③ إضافة إلى `.gitignore` ④ ثلاث نسخ من المهارة ⑤ ثلاثة مقاطع دخول (`AGENTS.md` / `CLAUDE.md` / `.cursorrules`، لا يكتب فوق قواعدك أبدًا) |

متكرر آمن: إعادة التشغيل لا تكتب فوق مستنداتك وقواعدك القائمة أبدًا؛ إنها تملأ الناقص فقط.

## 🛡️ الأمان والتصميم

- git الخطير (force push / reset --hard / clean محفوف بالمخاطر / rebase غير مصرح) غير موجود
- المزامنات ff-only فقط؛ الانحراف يتوقف ويبلّغ؛ النزاعات لا تُحل تلقائيًا أبدًا
- بيانات الاعتماد لا تدخل Git / الذاكرة / المقاييس / السجلات أبدًا
- التاريخ إلحاقي فقط أو موسوم «حل محله» — لا يُكتب فوقه أبدًا
- «تم» = دليل ميكانيكي (SHA بعيد + سجل نشر)، لا ادعاء
- توفير الرموز هدف من الدرجة الأولى: الفهرس أولًا، نماذج حسب المخاطرة، مخرجات محدودة، لا استدعاءات زائدة
